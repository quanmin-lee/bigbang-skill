## 合并建议

### 架构决策（来自 ARCH.md）

1. **独立模块**：新工具放在 `tools/excel-summarizer/`，不侵入现有业务代码
2. **最小依赖**：仅依赖 `openpyxl` 一个外部包，CLI 框架用 stdlib `argparse`，CSV 输出用 stdlib `csv`
3. **三阶段管道**：读 Excel → 汇总（sum）→ 写 CSV，三个阶段对应三个纯函数
4. **UTF-8 BOM**：CSV 使用 `utf-8-sig` 编码以兼容 Excel 直接打开中文 CSV
5. **V1 不做**：多列汇总、分组汇总、`.xls` 支持、大文件优化、JSON/Markdown 输出全部推迟

### 关键风险提醒

1. **openpyxl 环境依赖**：执行前必须 `pip install openpyxl`，否则测试全部失败
2. **CSV 编码**：`utf-8-sig` 确保 Excel 直接打开中文不乱码，测试读取时需使用相同编码
3. **pyproject.toml 包名映射**：目录连字符 vs Python 包名下划线的映射必须正确配置
4. **0 值 vs 空列语义**：当前 `summarize_column()` 无法区分"全 0 列"和"空列"，均返回 0.0。如果下游需要区分，V2 考虑返回 `Optional[float]` 或增加元数据
